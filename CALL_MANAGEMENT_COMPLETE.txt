API ENDPOINTS (15 TOTAL)
───────────────────────────────────────────────────────────────────────────────

CRUD Operations:
  GET    /api/calls                     - Get all calls (paginated)
  POST   /api/calls                     - Create new call
  GET    /api/calls/{id}                - Get call by ID
  PUT    /api/calls/{id}                - Update call
  DELETE /api/calls/{id}                - Delete call

Customer-Specific:
  GET    /api/calls/customer/{id}       - Get customer's calls
  GET    /api/calls/history/{id}        - Get complete history
  GET    /api/calls/last/{id}           - Get last call

Filtering:
  GET    /api/calls/status/{status}     - Filter by status
  GET    /api/calls/type/{type}         - Filter by type
  GET    /api/calls/employee/{name}     - Filter by employee

Statistics:
  GET    /api/calls/stats/today/count   - Total calls today
  GET    /api/calls/stats/today/incoming - Incoming calls
  GET    /api/calls/stats/today/outgoing - Outgoing calls
  GET    /api/calls/followups/today     - Follow-ups today
